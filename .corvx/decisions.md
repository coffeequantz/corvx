# Decisions

Architecture and product decisions for corvx, with dates and reasons. Changed through proposals accepted in CORVX.

## Website: static, dependency-free, in site/

2026-11-16: the project website lives in `site/` as plain HTML and CSS: no JS, no build step, no trackers, system fonts, relative paths, so it works as a file and on GitHub Pages under /corvx/. `site/assets/demo.gif` is a copy of `docs/demo.gif`; re-copy it when the demo changes. Only claim what the README says, including the "not ready for general use" status.

_Accepted 2026-11-16. Evidence: Website mission (s1794852249-3), branch corvx/s1794852249-3; the requirements came from the human._

## Website look: the TUI's terminal identity

2026-11-16: the site's identity is the TUI's.
- **Theme:** dark only (#0d1117 background), monospace throughout, with 1px BORDER (#262d36) frames like the TUI columns.
- **Colours:** exactly as in `crates/corvx/src/tui.rs`. ACCENT #79c0ff is the main accent, GREEN and RED mark done and failed, and LEAD purple #bc8cff marks the lead and knowledge. AMBER is only for a "needs you" cue, never an accent.
- **Logo:** the ASCII `LOGO` const, copied by script (never retyped), coloured like `logo_spans()` (pixels rgb(220,220,220), ░ shadows rgb(110,110,110)), with line-height 1. It is used wherever the wordmark appears.

When the TUI's colours or logo change, update the site to match.

_Accepted 2026-11-16. Evidence: Human's review of the website (follow-up round, commit c3ed163 on corvx/s1794852249-3): "no yellow/amber", "use the CORVX ASCII logo exactly as in the TUI", "lean into the retro terminal vibe"._

## Website look: black terminal identity, logo generated from the TUI

2026-11-16 (replaces the waiting proposal "Website look: the TUI's terminal identity"):
- **Background:** the site is black only (#000), monospace throughout, with 1px BORDER (#262d36) frames like the TUI columns.
- **Colours:** the TUI's, from `crates/corvx/src/tui.rs`. ACCENT #79c0ff is the accent, GREEN and RED mark done and failed, LEAD purple #bc8cff marks the lead and knowledge, and AMBER is only for a "needs you" cue.
- **Logo:**
  - It is `site/assets/logo.svg`, generated by `site/tools/logo.py` from the `LOGO` const, never drawn by hand and never set as text, because web fonts skew the block characters.
  - The generator draws █ as both rows of a cell, ▀ as the top row and ▄ as the bottom row. ░ is a checker dither. Pixels are rgb(220,220,220) and the shadow rgb(110,110,110).
  - Show it only at whole-number scales (24px or 96px tall) so the pixels stay crisp.
  - Regenerate it when the TUI logo changes.

_Accepted 2026-11-16. Evidence: Human's review rounds on the website (commits c3ed163, 57aa64e, 3dc343c on corvx/s1794852249-3): "render the TUI logo as an image file", "pure black background"; 99×22 rendered unevenly, 108×24 crisp._

## Website layout: minimal, essentials only

2026-11-16: the site is minimal: lots of negative space, few borders, no cards, few words. Sections are only: hero (logo, tagline, one-line pitch, status line, GitHub button), the demo GIF, "What it does" (a short list), "Get started", "Open source" (one line), and a footer. TUI colours are quiet accents; the accent blue is used only for links and the one button. A new section or feature list must earn its place; prefer adding a line to an existing section.

_Accepted 2026-11-16. Evidence: The human's item 3, "Minimalist and stylish, less is more… Cut or merge sections that do not earn their place"; implemented in commit 4ae1852 on corvx/s1794852249-3._
