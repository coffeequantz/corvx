### Project website · active

A simple static website for CORVX, loosely inspired by kilo.ai but simpler. It presents CORVX as free and open source (MIT OR Apache-2.0), shows the demo GIF from the README (docs/demo.gif), explains what CORVX adds above Claude Code, and links to the GitHub repo. It is honest about the current status (early, not ready for general use). Done when the site is in the repo, ready to host on GitHub Pages, and the human has reviewed it. Why: people need a place to understand CORVX quickly before reading the README.
