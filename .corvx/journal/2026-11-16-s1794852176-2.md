- I reviewed it in headless Chrome: dark, light (forced with `--blink-settings=preferredColorScheme=1`) and 360px.

**What went wrong.** Nothing material. Headless Chrome on macOS has a minimum window width, so `--window-size=375,...` gives a clipped screenshot that looks like overflow. Rendering the page in a 360px iframe gives a true phone view.

**Learned.**
- An agent writes commits without a Co-Authored-By trailer when the prompt says so explicitly and gives the exact `git commit -m` to use.
- The GIF's first frame is a fade-in, so still screenshots show it dim. That's expected.
